# Mulai pakai Fitrah di Android

1. Unduh APK universal, lalu buka dari notifikasi unduhan atau folder **Downloads**. Jika Android meminta izin untuk memasang aplikasi dari sumber ini, izinkan browser/pengelola file yang sedang dipakai, kemudian pilih **Install**.
2. Buka **Settings → Apps → Default apps → Home app**, lalu pilih **Fitrah Launcher**. Jika Android menampilkan pemilih Home, pilih Fitrah lalu **Always/Selalu**. Pada uji install bersih, tombol Home pertama tetap membuka launcher lama sampai pilihan ini diubah. Nama menu bisa berbeda pada tiap merek HP.
3. Di **Hari Ini**, tetapkan goal yang ingin kamu lihat. Pilih tindakan hari ini atau buat kegiatan, lalu mulai timer saat siap.
4. Buka **Jam** untuk melihat clock. Ketuk waktu kosong untuk membuka form kegiatan; isi hanya yang kamu mau, lalu simpan.

Untuk kembali ke launcher sebelumnya, pilih lagi dari menu **Home app** di Settings. Saat memperbarui owner preview ini, pasang APK di atas versi lama agar data lokal tetap ada. APK ini memakai sertifikat debug milik owner preview; APK dari Play Store atau kunci lain tidak bisa diperbarui dengannya. Data Android dan tiap web origin tersimpan terpisah, jadi buat backup sebelum upgrade penting.
